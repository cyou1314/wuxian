# 架构设计（2026-10-19）

## 产品形态

已确定为 Windows / macOS 桌面软件，采用 Electron + 现有 React Flow 画布。Next.js standalone 随安装包分发，Electron 主程序在本机回环地址启动服务，用户无需安装 Node.js。Web 开发模式继续保留。

## 模块

1. **画布渲染层**：无限画布、角色、17 列分镜表、7+5 提示词、图像与视频节点、任务队列。渲染进程开启 sandbox / contextIsolation，关闭 Node integration。
2. **桌面主程序**：窗口、文件菜单、原生项目对话框、自动恢复、独立账号会话、限定生成接口 IPC。本地 API 仅监听 `127.0.0.1`，每次启动使用随机端口和随机访问密钥。
3. **项目存储**：`.wuxian` 版本化 JSON，包含完整画布快照与任务，不包含登录凭证。自动恢复写入用户数据目录，通过串行临时文件替换防止并发写坏；退出前保存最新快照。
4. **账号与执行**：每账号独立持久化 Chromium session，用户在 Dola 页面登录。生成请求在账号页面上下文执行，只允许已知路径；Cookie 不通过 IPC 交给画布。移除账号时清理会话和缓存。
5. **额度调度**：现有 DolaAccountPool 按已知剩余额度优先分配账号，从响应解析消耗并更新当前运行内的额度。尚无独立配额接口、跨重启额度存储和跨日自动重置。
6. **打包**：electron-builder，Windows x64 NSIS，macOS Intel / Apple Silicon DMG 与 ZIP。Next.js 运行资源放在 `resources/web`；原生依赖在目标系统分别构建。打包后检查运行依赖，防止安装包缺少 Next.js。

## 数据流

```text
画布节点 → 任务队列 → 按额度选账号 → 受限桌面 IPC
  → 对应账号的 Dola 页面 → 提交 / 轮询 / 取直链
  → 任务状态更新 → 结果回填节点 → 本地自动恢复文件
```

现有 OpenAPI 仍使用服务端项目 JSON，与前端画布不是同一个数据源。本轮为其配置了可写的用户数据目录，尚未实现 OpenAPI 与本地画布的同步。

## 待验证与待实现

- Windows / macOS 真机安装、Dola 登录和实际生成。页面上下文不会自动保证通过平台签名或风控校验。
- 图片结果回取、媒体离线归档、正式签名与 macOS 公证、自动更新。
- 图层分离目前是参数编辑，智能剪辑目前导出决策表；尚无真实分层和视频渲染引擎。

不做账号批量注册，不绕过验证或风控。运行与发布说明见 [desktop.md](desktop.md)。
