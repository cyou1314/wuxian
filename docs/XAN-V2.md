# Xan 0.2 本地工作台升级

## 使用

- 点左上角 Xan 打开 API 管理：查看本机 Dola 账号、额度状态，修改引擎显示名称。未知额度按未知显示。
- 底部「资产库」包含画布和资产两页。资产索引保存在 `.wuxian` 项目；来源为上传、真实成功任务和本地处理。兼容实际任务字段 `succeeded`、`playUrl`、`imageUrl`。
- 添加菜单、右键和文件拖入均可上传图片/视频，单文件上限 50MB。参考图槽位支持上传、替换、移除。
- 「文本」是本地笔记。「导演台」和导演助手共用节点消息；支持预设指令与 @ 节点/资产。媒体引用目前仅传名称和地址，不表示已识别画面。
- 视频选中后，可创建片段重拍子节点、5秒创意片头，或本地截帧、替换、下载、放大。重拍复制原提示词与参数，修改要求追加到新提示词；不会修改原视频或自动提交。选区、续写来源仅为备注，现有 Dola 通路未发送这些额外参数。
- 片段剪辑、画面裁剪、音画分离及智能剪辑的顺序拼接调用本机 FFmpeg。远程成片先下载再上传；拼接素材应有一致的分辨率与音轨结构。原片保留，新产物进入资产库并创建视频节点；分离音频可下载。
- 拉片可播放视频、定位和抽帧、选择帧、存四维人工笔记；抽帧存入项目资产索引。
- 「分享 .wuxian」下载项目文件，并嵌入本机上传的图片、视频及截帧。嵌入素材合计上限35MB，项目总上限50MB；超限或源文件缺失会报错。远程成片保留原链接，能否跨机器访问取决于链接有效期。

## 画布操作

左键框选，中键平移，右键打开菜单。Space 按住临时平移，H 抓手，V 选择。

| 快捷键（macOS 用 Cmd 替代 Ctrl） | 操作 |
| --- | --- |
| Ctrl/Alt G；Ctrl Alt G | 分组；选择已有组时合并组成员 |
| Ctrl/Alt Shift G | 解组 |
| Ctrl D；Alt 拖动 | 复制节点及内部连线；拖出副本 |
| Ctrl C/V | 复制粘贴节点，保留组成员与角色归属 |
| Ctrl L | 连接所选节点 |
| Ctrl Enter | 所选视频加入生成队列；实际提交前另行确认 |
| Tab；Ctrl F | 添加菜单；搜索画布 |
| Alt Shift F | 本地 DAG 排列 |
| Ctrl + / - / 0 | 缩放 / 适应画布 |
| Ctrl Z / Ctrl Shift Z | 撤销 / 重做 |
| Delete；方向键 / Shift 方向键 | 删除；1px / 10px 微调 |

## 引擎与本轮验收边界

原 Dola 核心、签名、额度池、7+5提示词编译器未修改。类型、项目资产索引与 IPC 仅增加功能。

- 新增 `Engine` 接口与 Dola 包装器；纯文本请求使用已有 completion 消息信封，不添加猜测的 `chat_ability`。
- 对话、剧本扩写/改写、生成队列实际提交前均有额度确认。
- 图片生成的 `ability_param` 及结果读取、AI阅读/视觉消息格式尚未验通：入口明确禁用并说明原因。不能把 skill 类型确认或 pack 元信息当成生成闭环。
- 用户指定本轮仅验收本地，不调用 Dola。未执行真实对话、skill/pack、图片/视频生成或额度验收。
- 未增加超分、去字幕、主体消除、人声分离或音频生成。
- 修复智能剪辑节点直接返回新数组的状态订阅，避免 Zustand 重复渲染导致客户端崩溃。

## 构建和验证

先提供当前目标平台的 FFmpeg：`XAN_FFMPEG_PATH=/path/to/ffmpeg`。`desktop:prepare` 将其复制到忽略提交的 `desktop/bin/`；打包时放到应用 Resources/media。未提供时本地工具禁用并显示中文原因。FFmpeg 二进制不提交仓库。

```sh
npm run typecheck
npm run test:desktop
npm run desktop:prepare
npm run test:desktop:smoke
CSC_IDENTITY_AUTO_DISCOVERY=false npx electron-builder --mac --dir --arm64 --publish never
```

单元/集成测试覆盖项目兼容与存储、分组/复制引用、文本响应结构夹具，以及真实 FFmpeg 四类处理和输出解码。桌面隔离测试覆盖空白启动、文本编辑、上传鉴权、拖入、资产复用、API/导演界面、智能剪辑/视频节点、节点右键菜单、Cmd+Enter、视频替换/截帧/音画分离 IPC、参考槽位、原生下载、嵌入素材分享文件与重启恢复。协议夹具测试不等于真实 Dola 验证。

## 登录兼容修复

独立账号窗口允许 HTTPS 登录子窗口及初始 about:blank；子窗口沿用原账号分区，保留隔离、沙箱和禁止 Node 访问。去除 UA 中的应用标识，保留真实 Chromium 版本。页面加载失败在标题显示原因；不读取或搬运其他浏览器 Cookie。添加账号只建立本机会话，不能作为已登录的证据。
